# TugasWeb-Pertemuan3-Katalog

[![BETA](https://img.shields.io/badge/status-BETA-yellow)](https://github.com/USERNAME/TugasWeb-Pertemuan3-Katalog)

Ini adalah Katalog produk elektronik (gadget) yang saya buat berbasis HTML dan CSS (Tailwind via CDN). Situs ini berisi beberapa produk gadget kayak earbuds, smartwatch, laptop, dll dengan harga yang dibuat-buat.

## Apa Isinya?

- Halaman katalog produk responsif (mobile, tablet, desktop)
- Navbar dengan hamburger menu di mobile
- Hero banner
- Filter kategori (Perangkat, Audio, Wearable, Aksesoris)
- Grid produk (gambar + info + harga + tombol Beli)
- Footer
- Tailwind CSS (via CDN)

## Kekurangan/Lagi Dikerjain

- Tombol "Beli" cuma placeholder (belum ada backend/checkout)
- Link navbar (Beranda, Produk, Kontak) masih anchor kosong
- Harga produk dibuat-buat, bukan harga asli
- Belum ada halaman detail produk
- Gambar produk dari Unsplash, bukan foto produk asli
- Belum ada validasi/search bar

## Rencananya

- Tombol Beli yang beneran fungsional (atau minimal ke halaman checkout dummy)
- Halaman detail per produk
- Search bar
- Footer dengan link sosial media
- Penyempurnaan animasi & transisi
